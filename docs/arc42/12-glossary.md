# 12. Glossary

| Term                                      | Definition                                                                                                                                                                                              |
|-------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **FHIR**                                  | HL7 Fast Healthcare Interoperability Resources — standard for healthcare data exchange.                                                                                                                 |
| **Profile / StructureDefinition**         | A FHIR conformance resource constraining a base resource for a specific use case.                                                                                                                       |
| **Profile canonical**                     | The unique URL of a profile, optionally with a version (`url\|version`).                                                                                                                                |
| **FHIR package (NPM package)**            | A versioned distribution of FHIR conformance resources, packaged as `.tgz` (`name#version`).                                                                                                            |
| **Package group**                         | A named set of FHIR packages selected for a profile version and validity period.                                                                                                                        |
| **Profile family**                        | A set of profiles sharing a canonical base URL and release cycle.                                                                                                                                       |
| **Validity period**                       | An inclusive date range binding a package group to a profile version. A period without `validTill` is open-ended and can be used when no date is available.                                             |
| **validityDateSource**                    | Optional FHIRPath expression in a module profile definition used to extract the date for package selection.                                                                                             |
| **Validation module**                     | External JAR with a `META-INF/config.yaml` manifest conforming to `validation-module-api` spec 3.0. It declares profile families, package groups, and module validation rules.                          |
| **ValidationModuleManifest**              | The API record representing a module's parsed YAML configuration.                                                                                                                                       |
| **Module template project**               | External starting repository for publisher-owned module projects. Supplies the layout, configuration files, provider registration, and example tests. It is not a runtime dependency.                   |
| **validation-module-parent**              | Published Maven parent for module builds. Manages CLI snapshot generation at `generate-resources` and built-JAR validation at `verify`, activated through the child's exec plugin declaration.          |
| **Module release version**                | Publisher-defined version of a module's content and policies. Independent of the Reference Validator product release and of the FHIR packages it carries.                                               |
| **configSpecVersion**                     | Manifest format identifier, currently `3.0`. Not the module release version or a negotiated engine compatibility range.                                                                                 |
| **Module name**                           | Manifest identity used for runtime selection. Not necessarily the Maven artifact ID. First matching name wins when several JARs declare it.                                                             |
| **Snapshot**                              | The fully expanded form of a StructureDefinition (all inherited elements resolved).                                                                                                                     |
| **Snapshot generation**                   | Producing snapshots for a package's StructureDefinitions and repackaging the result.                                                                                                                    |
| **Message transformation**                | Rule rewriting the severity of an engine message (per module).                                                                                                                                          |
| **Suppression rule**                      | Rule removing messages whose content matches its expression. It can hide genuine errors if scoped incorrectly.                                                                                          |
| **Ignored terminology canonical**         | CodeSystem or ValueSet canonical used to downgrade matching retained messages to informational severity. It does not establish that the terminology was checked.                                        |
| **Valid result**                          | A processed validation result without ERROR or FATAL findings. Does not guarantee clinical correctness or complete terminology coverage.                                                                |
| **Recursive validation**                  | Context policy enabling embedded resources to be checked against their own declared profiles. Distinct from directory traversal and first-child profile extraction for module package selection.        |
| **Terminology server**                    | Remote service for ValueSet expansion / terminology validation (e.g. ZTS/bfarm).                                                                                                                        |
| **Referee (Schiedsrichter)**              | The validator's authoritative role for automated validity decisions in the TI.                                                                                                                          |
| **BCE**                                   | Boundary–Control–Entity package organization used inside `referencevalidator-lib`; these are not separate Maven modules.                                                                                |
| **HL7 Core Validator**                    | The FHIR validation and snapshot engine (`org.hl7.fhir.validation`), version 7.0.1 in the reviewed BOM. Replaces the earlier HAPI validation engine in product version 3.0.0.                           |
| **FHIR release**                          | The `FhirRelease` abstraction. The code provides R4 and R5 implementations; R4 is the default.                                                                                                          |
| **SnapshotArchiveCache**                  | File-backed cache of successful generated package archives.                                                                                                                                             |
| **Validation-context template**           | Batch-local initialized context retained for one context configuration and ordered package set; it is used only as a source for isolated clones, never to validate a resource.                          |
| **Template lease**                        | A batch-provider handle that protects a package-set template from eviction and creates a distinct resource-owned validation context.                                                                    |
| **Temporary terminology-cache ownership** | Shared lifecycle of a library-created terminology-cache directory. Context clones retain ownership, and the directory is removed after the last owner closes. Explicit cache paths remain caller-owned. |
| **In-flight validation**                  | A validation task submitted and not yet completed; the CLI bounds this count with `--parallel-threads`.                                                                                                 |
| **Reference Validator library**           | Maven artifact `referencevalidator-lib`, containing public interfaces, model types, and implementations.                                                                                                |
| **TI**                                    | Telematikinfrastruktur — the German healthcare telematics infrastructure.                                                                                                                               |
| **ZTS**                                   | Zentrales Terminologieserver (central terminology server, bfarm).                                                                                                                                       |
| **ArchUnit**                              | Library for testing architecture rules in code.                                                                                                                                                         |
| **JPMS**                                  | Java Platform Module System. A `module-info.java` exists in `validation-module-api`; the other Maven modules are not described as JPMS modules here.                                                    |
